# Про НЕЁ

Адаптивный сайт бьюти-студии. Статический HTML, CSS и JavaScript без сборки. Публикуется директория `dist/`.

Проверка содержимого без JavaScript: `python scripts/check_static_content.py`. Она также выполняется основной командой `python scripts/check_seo.py`: проверяются 73 строки прайса с названиями, длительностью и суммами, страницы шести направлений, доступность готовых страниц по обычным ссылкам и HTML будущих опубликованных статей. Текст из скриптов и JSON-LD не засчитывается вместо основного содержимого. Подробности переноса на домен и проверки в Яндекс Вебмастере: `SEO_GEO_HANDOFF.md`.

## Контент

- Согласованные баннеры: `hero-desktop.webp`, `hero-tablet.webp`, `hero-mobile.webp`. Цвет интерфейса — `#A5576D`.
- Логотип — точный исходный прозрачный PNG заказчика, без перерисовки. У ссылки логотипа нет фона, рамки или тени.
- Фотографии услуг и абонементов — сгенерированные иллюстрации, не фотографии клиентов или помещения. Финальные задания и пути перечислены в `IMAGE_ASSETS.md` и `ASSET_UPDATE_2026-10-22.md`.
- На главной используются шесть новых квадратных изображений `service-*-square-v1.webp`, по одному для каждого направления. Полные промпты и пути — в `IMAGE_ASSETS.md`. Все карточки имеют точные пропорции 1:1, включая область подписи поверх фотографии; на телефоне — две колонки, на большом экране — три.
- Отзывы намеренно оставлены пустыми карточками до выбора владельцем.
- Адрес, телефон, имена и опыт специалистов перенесены из карточки студии: https://yandex.ru/maps/org/pro_neyo/174748430473/ .
- Все 18 ссылок записи на шести страницах сразу открывают https://dikidi.net/ru/record/738151 . Промежуточный диалог выбора способа записи удалён. Телефон и построение маршрута остаются самостоятельными контактами.

## Абонементы

После специалистов расположены два абонемента — 5 000 ₽ на бежевом фоне и 10 000 ₽ на вишнёвом. Каждая карточка состоит из фотографии сверху (3:2) и отдельной области описания тарифа снизу. На телефоне карточки идут друг под другом, разделённые фоном сайта. Для 5 000 ₽ используется новый горизонтальный `membership-5000-v3.webp` с оптически центрированной композицией, целым полотенцем и равновесием по краям. Для 10 000 ₽ сохранён `membership-10000-v2.webp` с кадрированием к нижней предметной композиции средствами CSS; текст на фотографии не размещается.

Условия перенесены из присланного прайса: один месяц с даты приобретения, использование в текущем месяце без переноса на следующий. Данные — `dist/content/memberships.json`. Ссылка под карточками ведёт к отдельному прайсу `/prices/`.

## Приложение

Сохранена исходная композиция `app-visual.webp` с телефоном, подиумом и объёмными фигурами. Новый светлый скриншот App Store `app-store-light-clean.webp`, на основе `IMG_3451.jpeg`, встроен в экран средствами HTML/CSS. Верхняя строка очищена: 9:41, стандартный чёрный Dynamic Island, 100% заряда, без стрелки геолокации. Подложка экрана белая.

Под фотографией приложения находится единственная кнопка «Скачать приложение», которая открывает выбор официального App Store или Google Play. Дублирующая кнопка и подпись «Ваша запись. Ваше время.» убраны. Сайт не собирает данные посетителей; запись обслуживается внешним сервисом.

## Поведение прайса — свёрнутые разделы

При обычном входе на `/prices/` все восемь групп закрыты. Группы образуют один аккордеон: открытие новой закрывает предыдущую; повторное нажатие закрывает текущую. Это поддерживается нативным `details name` и JavaScript для старых браузеров. Возврат на полный прайс также сбрасывает раскрытые группы. Прямые ссылки на конкретную категорию или процедуру раскрывают только соответствующую группу; повторный клик по той же категории работает. Генератор сохраняет это поведение при следующей сборке. Проверено в браузере: исходно 0 открытых групп, переключение косметология → массаж, закрытие повторным нажатием, повторная ссылка детского массажа, прямой URL SPA и новый вход в полный прайс.
